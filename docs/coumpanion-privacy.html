Coumpanion for Android Privacy Policy

Updated November 24, 2026.

Coumpanion is free. Core Android tracking requires no account, API key, or server. Coumpanion has no ads, subscriptions, or analytics.

On-device tracking

Coumpanion saves the providers and timing of your manual sessions on your phone so it can restore them when reopened. A manual timer records the time you track. It does not inspect another app’s conversations or determine whether an AI is working.

The Dynamic Island uses Android’s optional Display over other apps permission to draw its own status panel. It does not read the screen, record taps in other apps, or use an Android Accessibility Service.

Notification access in Full

Full offers optional notification access. Android grants this permission device-wide. Coumpanion checks the package against its supported list and your selection before reading the notification title. Titles used in the island stay in memory. The bounded local notification history stores the provider, receipt time, and event category. Coumpanion does not store notification bodies or titles in that history. Standard has no notification listener.

You can turn off individual watched apps, clear notification history in Coumpanion, or revoke notification access in Android Settings. Revoking access clears the saved notification history when Coumpanion next detects the change.

Optional connections

Pairing connects to the computer or compatible server you choose. The connection can carry agent status, approval requests and your responses, or chat content when you use those features. The phone stores pairing details locally. If you enable a compatible relay, it forwards encrypted link traffic. Removing the pairing disconnects the link and removes its saved connection details.

With Coumpanion Server, the server you run holds the DeepSeek API key. When you send a chat message through that server, it forwards the message to the configured provider. The server operator and provider govern processing on their systems. Launching an external AI opens an app or website governed by that provider’s policy.

Retention and deletion

Active manual sessions and custom provider settings stay on this device. The bounded Session History retains provider labels, timestamps, tracked duration, source, and final status. Delete individual records or clear history from Settings. Preferences and local feature data remain until you clear the corresponding feature or clear Coumpanion’s storage in Android Settings. Clearing app storage or uninstalling an edition removes its local app data. Each edition has separate storage.

Session tracking records contain timing and status metadata. Optional desktop chat is a separate feature with a local history you can clear from Chat. Imported provider logos are stored as resized local images. Share uses the selected Android text receiver, explicit clipboard copy, or a desktop chat draft when you choose one. A local diagnostics report contains build and permission states and aggregate counts.

Project and support

Coumpanion for Android is maintained in the Neyoiooo/coumpanion repository. Use the repository’s issue tracker for support. Keep private notification text, prompts, pairing links, and credentials out of public issues. The project credits Louis Raillé’s Coucou and Rhytam Biswas’s Android port.
